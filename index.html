Linked List Structure

Live visualization of in-memory node pointers

LIVE DSA

Each node holds case information, a list of evidence nodes, and a pointer .next to the successive case.

This is a singly linked list. Each node stores case data and a pointer to the next node. Deletion updates prev.next = curr.next and sorting operates directly on node references.
