# Crime Management and Evidence Organization System

This folder contains the browser prototype and its SLA Stage 3 report.

## Open the prototype

Open `index.html` in a modern browser. The page uses fictional sample cases. Added and edited records are saved in that browser's local storage.

## Contents

- `index.html` — interactive case management prototype.
- `SLA3_Report_Crime_Management_System.md` — Stage 3 report.

The prototype is front-end only. It does not connect to a backend, accept evidence file uploads, or support shared accounts.
