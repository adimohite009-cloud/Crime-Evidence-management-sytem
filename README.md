# Crime Management and Evidence Organization System

A browser-based prototype for demonstrating crime case record management.

**Live prototype:** https://adimohite009-cloud.github.io/Crime-Evidence-management-sytem/

## Features

- Case overview and case register.
- Search and crime-type filtering.
- Add, update and delete case records, with duplicate-ID checks and deletion confirmation.
- Fictional sample records and browser-local persistence.

Open `index.html` in a modern browser to use the prototype. Added and edited records are saved in that browser's local storage.

The prototype is front-end only. It does not connect to a backend, accept evidence file uploads, or support shared accounts. Use fictional data only.
